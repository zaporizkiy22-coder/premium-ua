# PREMIUM UA — офіційний сайт

## Файли
- `index.html` — головна сторінка з усіма 8 розділами
- `team.html` — склад гільдії
- `administration.html` — адміністрація
- `awards.html` — галерея оригінальних грамот
- `reviews.html` — відгуки
- `style.css` — чорно-золотий дизайн та адаптація для телефонів
- `script.js` — мобільне меню
- `assets/` — надані зображення

## Як опублікувати через GitHub Pages
1. Увійдіть на https://github.com і створіть новий репозиторій, наприклад `premium-ua`.
2. Завантажте в репозиторій усі файли й папку `assets` із цього архіву. Важливо: `index.html` має лежати в корені репозиторію.
3. Відкрийте **Settings → Pages**.
4. У розділі **Build and deployment** виберіть **Deploy from a branch**.
5. Виберіть гілку `main` і папку `/ (root)`, натисніть **Save**.
6. Дочекайтеся публікації — GitHub покаже адресу сайту в цьому ж розділі Pages.

Усі зовнішні кнопки Telegram і TikTok уже мають задані посилання. Фото грамот відкриваються в оригінальному розмірі при натисканні.
